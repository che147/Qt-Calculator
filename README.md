# 带键盘事件的计算器（Qt 6 Widgets）

东莞理工学院《Qt应用程序开发》实验一：设计一个带键盘事件的计算器，
支持加减乘除、小数输入、退格、清除、正负号与百分号，鼠标与键盘复用同一套处理逻辑。

## 功能特性

- 四则运算（`+` `-` `×` `÷`），支持连续运算（如 `2×3+4=`）
- 小数输入，同一操作数内自动拦截重复小数点（`1..2` → `1.2`）
- 退格（`⌫`）、清除（`C`）、正负号（`±`）、百分号（`%`）
- 键盘输入与鼠标点击复用同一个 `processKey()`，行为完全一致
- 除数为 0 进入错误状态（显示"错误"与原因），输入数字或按 C 恢复
- 计算完成后继续输入：按数字开始新运算，按操作符基于结果继续运算

## 键盘映射

| 按键 | 功能 |
| --- | --- |
| `0` ~ `9`（含小键盘） | 数字 |
| `.` / `,`（含小键盘） | 小数点 |
| `+` `-` `*` `/` | 加 / 减 / 乘 / 除 |
| `Enter` / `=` | 等号 |
| `Backspace` | 退格 |
| `Esc` / `Del` | 清除 |

## 构建方法（qmake + MinGW）

```
qmake calculator.pro
mingw32-make -j4        # 或在 Qt Creator 中直接构建运行
```

要求：Qt 6.x（MinGW 版本）及配套 MinGW 工具链。

## 工程结构

```
calculator.pro    qmake 工程文件
mainwindow.h/.cpp 计算器逻辑（状态管理 + 统一按键处理 + 键盘事件）
mainwindow.ui     UI 设计器界面（布局 + 样式表）
```

## 状态模型说明

- `m_firstOperand`：第一个操作数
- `m_pendingOperator`：待执行的操作符
- `m_currentInput`：当前正在输入的操作数
- `m_justEvaluated`：刚按过 `=`，决定后续输入是"继续运算"还是"新运算"
- `m_errorState`：错误状态（除零），屏蔽运算类输入直到恢复
